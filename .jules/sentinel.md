## 2024-05-24 - Unrestricted File Upload Vulnerability in Memories API
**Vulnerability:** The `/api/memories/upload` endpoint allowed users to upload files of any extension (e.g., `.html`, `.svg`, `.exe`) and size because it blindly saved files using `os.path.splitext(file.filename)[1]`.
**Learning:** In FastAPI, accepting `UploadFile` without explicit extension or MIME type checks allows arbitrary files. Because these files are then served via `StaticFiles` at `/api/uploads`, this creates a severe Stored XSS vulnerability (if an attacker uploads an `.html` or `.svg` file containing scripts) and a DoS risk if massive files are uploaded.
**Prevention:** Always enforce a strict allowlist of file extensions (e.g., `[".jpg", ".png", ".webp"]`) using `os.path.splitext` combined with a `.lower()` string check. Additionally, enforce max file size limits directly on the uploaded stream using `file.file.seek(0, 2)` and `file.file.tell()` before processing or saving the file.
