## 2025-02-23 - Native Node Tests for Frontend API
**Learning:** Node.js native `node:test` and `node:assert` along with `node:internal/test_runner/mock` provide a robust testing framework directly integrated into the environment. When using `mock.timers.enable`, only `setTimeout` should be enabled because mocking `clearTimeout` may cause tracking issues and errors (`"The property 'options.apis' option clearTimeout is not supported"`). Additionally, Promises initiated before the timer tick must be given a chance to settle using `await new Promise(resolve => setImmediate(resolve))` so the internal logic has a chance to execute before skipping time.
**Action:** Use native Node.js tests for utility scripts. Configure MockTimers with `{ apis: ['setTimeout'] }` and carefully manage Promise resolution bounds prior to ticking the mock timer.
